# ShiftGuard-HAI

Code, configurations and results for the article
**"Trained Yesterday, Blind Tomorrow: Operating-Point Shift and Shift-Robust Anomaly Detection in Industrial Control Systems"** (submitted to IEEE Access).

It contains:
- a deployable-evaluation benchmark of 11 unsupervised detectors (incl. TranAD and GDN) on HAI 21.03, 22.04 and 23.05;
- the cross-release study, recalibration study and input-representation study;
- **ShiftGuard** (`src/shiftguard.py`): PCA on differenced inputs OR a self-re-baselining level check;
- the four-release study (HAI 20.07–23.05), the shift analysis, the SKAB external check, the hold-out protocol and all result tables.

## Data (not redistributed)
| Dataset | Source | Place in |
|---|---|---|
| HAI 20.07, 21.03, 22.04, 23.05 | https://github.com/icsdataset/hai | `data/20.07/`, `data/21.03/`, `data/22.04/`, `data/23.05/` |
| SKAB v0.9 | https://github.com/waico/SKAB | `data/skab/` (the repository's `data/` folder) |

## Environment
Python 3.11+ (tested with 3.13), CPU only (2 cores, 7 GB RAM is enough). `pip install -r requirements.txt`.

## Reproduce (run from the repository root)
```bash
# 1) benchmark (RQ1-RQ5): results/v2, results/*.csv
python src/run2.py PCA,Envelope,IForest,kNN,OC-SVM,MLP-AE,LSTM-AE,Transformer,USAD   # SEED=0..4, TRANSFORM=none|diff|rollbase, SETTINGS=within|all
python src/adapt.py; python src/sensitivity.py; python src/stats.py
# 2) four-release ShiftGuard study (RQ6)
python src/run3.py; REPS=ndiff SKIPLEVEL=1 python src/run3.py; python src/revin_hai.py; python src/eval3.py
python src/theory_check.py; python src/theory_check_v4.py; python src/shapes3.py; python src/localise3.py
# 3) v4 checks
python src/fair.py; python src/level59.py; python src/fairx.py
python src/holdout.py; python src/holdout_eval.py; python src/skab.py; python src/analysis4.py
# 4) tables and figures
python src/figs.py; python src/figs2.py; python src/figs3.py; python src/figs4.py
```
Every number in the article is in `results/` (CSV). Large intermediate score files are not included; they are regenerated by the scripts.

## Metric check
`validate/etapr_mirror_test.py` compares our eTaPR with a loop-based mirror of the reference package.
`validate/etapr_check.py` compares it with the official package (`pip install etaprpkg`) on random cases.
